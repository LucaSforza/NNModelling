Install NNModelling

NNModelling is a visual editor and DSL for designing neural networks, compiled to PyTorch/Lightning training pipelines. One command fetches, builds, and starts the editor together with a local training backend — the editor is served from your own machine, not from this site.

One command

$ curl -fsSL https://lucasforza.github.io/NNModelling/install.sh | bash

The installer:

  1. clones the NNModelling repository (or updates an existing checkout) into $HOME/.local/share/nnmodelling,
  2. installs the pnpm dependencies and builds the editor,
  3. ensures a local Valkey is running — it reuses a healthy instance, or starts a repository-local process when the valkey-server binary is available,
  4. starts the companion: the editor and training backend on the same origin at http://127.0.0.1:8000.

Open http://127.0.0.1:8000, pair the Training Sidebar with the default http://127.0.0.1:8000 URL, and train locally. On the first start the companion provisions the local administrator token automatically (mode 0600), so no separate setup step is needed. When the companion exits, the installer stops only the Valkey process it started.

Prerequisites (checked, not installed)

The script checks for these tools and fails with instructions when one is missing — it never installs them for you:

  • Git — to clone the repository.
  • Python 3.12+ and uv — the companion runs on uv; the environment is created automatically.
  • Node.js 18+ and pnpm 10+ — to install dependencies and build the editor.
  • Valkey 8 — either an already running instance, or the valkey-server binary for the installer to start a repository-local process. Alternatively run the bundled Docker deployment (just --justfile converted/backend/justfile valkey or docker-up) before the command.

Options

Set these environment variables before the command:

  • NNM_DEST_DIR — checkout destination (default $HOME/.local/share/nnmodelling).
  • NNM_REMOTE_REPO — repository URL to clone/update.
  • NNM_BRANCH — branch to check out (default master).
  • NNM_VALKEY_URL / NNM_VALKEY_PORT — Valkey connection (default valkey://127.0.0.1:6379/0 / 6379).
  • NNM_BACKEND_HOST / NNM_BACKEND_PORT — companion bind settings (default 127.0.0.1:8000).

For example:

$ curl -fsSL https://lucasforza.github.io/NNModelling/install.sh | NNM_DEST_DIR=~/nnmodelling bash
The installer never overwrites a destination it does not own (a non-empty directory that is not an NNModelling checkout), never prints secrets, and the companion never proxies or routes remote jobs. The Training Sidebar keeps its URL and pairing workflow, so you may equally connect it to an independently managed remote backend instead of the localhost one.
