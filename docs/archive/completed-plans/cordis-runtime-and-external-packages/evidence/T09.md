## Implementation correction made during verification

T09 exposed two initiative-internal integration gaps: the package manager was
not mounted in the editor and `Diagram` did not compose the IndexedDB store.
The final implementation wires the visible manager to transactional
install/activate/remove operations, restores installed metadata on reload, and
activates exact installed packages before UI or MCP node creation. The
BrowserRPC handler remains a thin proxy and now supports only the asynchronous
activation needed for that exact create operation.
