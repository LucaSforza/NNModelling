# Documentation archive

This directory preserves historical NNModelling plans, implementation records,
reviews, reports, and superseded architecture notes. Its contents are retained
for traceability and are **not authoritative descriptions of the current
system**.

Use the current documentation instead:

- `docs/README.md` for the internal documentation map and lifecycle rules;
- `docs/knowledge/` for current architecture, contracts, testing, and
  operational knowledge;
- `docs/plans/active/` for open work from draft through execution;
- `docs/orchestrators/` for Codex- and OpenCode-specific orchestration notes;
- package-local `AGENTS.md` files for active agent instructions.

Archive categories:

- `completed-plans/` contains implemented design and task packages;
- `superseded/` contains architectures and references replaced by newer
  sources;
- `reports/` contains historical reports and reviews.

Do not update archived documents to describe new behavior. Correct current
documentation or create a new plan instead. Git history remains the source for
the chronology of changes to these records.
