# Active initiatives

This directory contains open initiatives in `draft`, `ready`, `in_progress`, or
`blocked` state.

Current initiative:

- [`editable-edge-routing`](editable-edge-routing/plan.md) — persistent,
  interactive UML-style edge routing for the Svelte editor.
- [`declarative-type-system`](declarative-type-system/plan.md) — draft redesign
  of tensor signatures, expressions, constraints and subflow/Join inference.

Create a new draft subdirectory from `../templates/plan.md`, then promote its
status as decisions and execution progress. Completed, superseded, historical
backlogs, and closed-issue gap analyses belong in `docs/archive/`, not here.
